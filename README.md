# Marine DataLab — sitio web

Sitio estático de **Marine DataLab · Applying AI to Ocean** (La Paz, B.C.S., México).

- `index.html`: página completa (ES / EN / SV), sin dependencias de compilación.
- `favicon/`: íconos del sitio.
- `og-image.png`: imagen para compartir en redes.

Publicado con GitHub Pages: https://rcavieses.github.io/marine-datalab/

Para enlazar un dashboard, edita el arreglo `DASHBOARDS` en `index.html` y llena el campo `url`.
